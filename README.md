# BRIDGE-AI 스마트교육

2026. 스마트교육 실천사례 연구대회
「AI로 연결하고, 예술로 실천하며, 진로로 성장하는 BRIDGE-AI 스마트교육」 웹 플랫폼

주소: https://edunity21.github.io/smart/

## 폴더 구성

- `index.html` — 플랫폼 (홈 · 연구 설계 · BRIDGE ①~④ · 성과 · 일반화 · 현장 기록 · 자료실)
- `report.html` — 연구보고서 · 요약서 전문
- `img/a`, `img/b`, `img/c` — 사진 각 90개
- `img/d` — 사진 30개, `img/s` — 요약서 사진 31개

## 올리는 방법 (GitHub 웹, 한 번에 100개까지)

1. 내 컴퓨터에서 `img` 폴더 안의 `b`, `c`, `d`, `s` 폴더를 잠시 바탕화면으로 옮겨 `img` 안에 `a`만 남깁니다.
2. `smart` 레포 첫 화면의 Add file → Upload files(빈 레포는 "uploading an existing file")에 `index.html`, `report.html`, `README.md`, `img` 폴더를 함께 끌어다 놓고, 진행 막대가 모두 사라지면 Commit changes를 누릅니다. (93개)
3. 레포에서 `img` 폴더를 클릭해 들어간 뒤 Add file → Upload files에 `b` 폴더를 끌어다 놓고 Commit합니다. (90개)
4. 같은 방법으로 `img` 폴더 안에서 `c` 폴더를 올립니다. (90개)
5. 마지막으로 `img` 폴더 안에서 `d`와 `s` 폴더를 함께 올립니다. (61개)
6. Settings → Pages에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
7. 1~2분 뒤 https://edunity21.github.io/smart/ 에서 확인합니다.

## 고칠 때

사진은 그대로 두고 `index.html`, `report.html`만 같은 자리에 다시 올리면 덮어써집니다.
